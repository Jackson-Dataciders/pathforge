# Create a course

1. In the `courses/` vault, create a folder for the course.
2. In that folder, create a note named `README` and insert the `course-readme` template.
3. Fill in `topic`, `course_language`, and `code_language`, then describe what the course should teach in `## Description`. Use `none` for `code_language` when the course has no code. Do not edit `status`.
4. In VS Code, select the `course-planner` agent in Copilot Chat, attach the course `README.md`, and send it.
5. When the planner finishes, click **Build course**.
